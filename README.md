# Virtual Caretaker Chatbot
Simple LLM-integrated chatbot for practicing student nurses

Chat logs will be saved for reference and feature improvements.

## How to Use
1. Input Claude API key to the left.
 - Refreshing will result in the key being erased as well. If you're resetting, make sure to put in the key first.
2. Begin speaking with the chatbot.
3. Save conversation if you feel like you're done. The chatbot will continue speaking (see Known Issues).

## Known Issues
- No real stopping point for the conversation.
